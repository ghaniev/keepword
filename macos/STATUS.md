# Keepword — статус проекта

Приложение для заметок со встреч для macOS 15+ (Apple Silicon): запись звонков без бота, транскрипция и спикеры на устройстве, саммари, чат и поиск по встречам. Как собрать и запустить — в [README.md](README.md).

Обновлено: 21.10.2026.

## Что сделано

### Запись и транскрипция
- Запись микрофона и системного звука (Core Audio process tap, без бота). Режимы: оба / только микрофон / только система. Пауза, mute, закладки (⌘B).
- Смена устройства во время звонка (AirPods, другой микрофон или выход): запись продолжается в те же файлы, пропуск заполняется тишиной.
- Защита от сбоев: после `kill -9` запись читается и обрабатывается при следующем запуске.
- Живая транскрипция во время звонка. Итоговая — на выбор: Parakeet (v3, Ultra, Redux, v2) или Whisper (WhisperKit) на Neural Engine со скачиванием моделей в настройках, либо облако (OpenAI, Groq, Deepgram, OpenAI-совместимый сервер).
- Разделение по спикерам (pyannote + WeSpeaker): голос узнаётся в следующих встречах; мастер «кто это» для новых голосов.
- Импорт аудио и видео перетаскиванием.
- Определение начала и конца звонка (Zoom, Teams, Meet, Slack…), предложение записать встречу из календаря.
- Плавающая панель встречи: заметки, живой транскрипт, подготовка (прошлые встречи с теми же людьми).
- Снимки экрана во время звонка; вложения.

### AI
- Провайдеры:
  - встроенная локальная модель (Qwen через llama.cpp, выбор под объём памяти Mac);
  - подписка ChatGPT или Claude через CLI (`codex`, `claude`), без API-ключа;
  - API-ключи (OpenAI, Anthropic, Gemini, OpenRouter, DeepSeek);
  - Ollama / LM Studio.
- Саммари по шаблонам: 9 встроенных и свои. Длинные встречи — map-reduce.
- Чат по встрече и по всем встречам: цитаты с переходом к моменту, упоминания `@Имя`, `@тег`, временные диапазоны.
- Гибридный поиск: FTS5 + встроенные эмбеддинги `paraphrase-multilingual-MiniLM-L12-v2` (русский запрос находит английский текст). «Похожие документы».
- Живые запросы: сохранённый вопрос за период, запуск вручную, ежедневно или еженедельно.

### Организация
- Папки с вложенностью, теги, люди (карточки, слияние), задачи (action items) со сроками и ответственными.
- Календарь: неделя / рабочая неделя, календари macOS и Google по закрытому iCal-адресу.
- Экспорт в Markdown (Obsidian / Logseq), отправка задач в «Напоминания», корзина на 30 дней.

### Интеграции
- **Свой MCP-сервер** (Keepword как сервер): Claude Code / Claude Desktop читают встречи, транскрипты и задачи. Только `127.0.0.1`, токен в Связке ключей.
- **Внешние MCP-серверы** (Keepword как клиент): stdio и HTTP, импорт конфигурации Claude Desktop, секреты в Связке ключей.
- **Задачи в Kaiten** через [kaiten-mcp-server](https://github.com/ghaniev/kaiten-mcp-server):
  - откуда создавать: «Создать задачи…» у блока задач, контекстное меню задачи, «Создать задачу…» из заметок;
  - форма строится по схеме инструмента, доски, колонки и ответственные выбираются из списков, выбор запоминается;
  - у созданной задачи появляется ссылка на неё.

### Интерфейс

- Настройки — список разделов слева, как в «Системных настройках».
- Иконка приложения.

### Исправления записи и диаризации
- Таймер записи идёт ровно по секундам: время и уровни звука вынесены из общей модели, индикаторы громкости больше не перерисовывают всё окно.
- Повторная запись: исправлено падение при перезапуске микрофона на старом аудиодвижке. Старт и стоп записи выполняются вне главного потока и по очереди.
- AirPods: микрофон больше не перезапускается по кругу, когда наушники переключаются в режим звонка.
- Если служба звука macOS (coreaudiod) не отвечает, через 8 секунд показывается подсказка.
- Окно «Разрешения»: микрофон, звук системы, запись экрана, календари, напоминания. Открывается при запуске, пока не хватает обязательных разрешений, а также из меню и настроек.
- Диаризация:
  - один спикер встречи — один человек;
  - до 5 образцов голоса на спикера, без «уплывания» исходного;
  - слова привязываются по наибольшему пересечению, одновременная речь помечается;
  - число участников из календаря задаёт верхнюю границу, «Переопределить спикеров…» — точное число.

## Где что лежит
Структура кода и правила слоёв описаны в [README.md → Project structure](README.md#project-structure). Коротко:
- `Sources/MeetNotes/App` — точка входа и `AppModel`;
- `Core` — логика без интерфейса (БД, аудио, AI, MCP, календарь);
- `Features` — экраны по фичам;
- `DesignSystem` — общие компоненты;
- `Dev` — самотест, демо, тестовые флаги;
- `Resources/ru.lproj` — переводы, `Resources/assets` — иконка.
